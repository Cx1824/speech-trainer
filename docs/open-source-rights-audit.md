## 本次公开范围

GitHub `v0.1.0` 只发布本仓库中的源代码、测试、文档和项目自制演示素材。以下内容
不进入公开仓库或 Release：

- `.env`、API Key、数据库、简历、训练记录、报告、录音和日志；
- Windows 好友私测 ZIP、随包运行时、wheel 和本地语音模型；
- AI 生成的商业宣传片、配音、第三方生成画面及其本地合成脚本；
- FLEURS 原始音频和其他外部评测音频。

## 第三方代码、模型和数据

- npm 直接依赖为 MIT 或 Apache-2.0。
- Python 直接依赖以 MIT、BSD、Apache-2.0、ISC 等宽松许可证为主；`edge-tts`
  除单个 MIT 文件外采用 LGPLv3，项目仅将其作为未修改的外部依赖声明，不复制其
  源码或二进制到公开仓库。
- `sherpa-onnx` 运行时代码采用 Apache-2.0。
- Google FLEURS 元数据采用 CC BY 4.0，仓库保留数据集名称、来源、许可证和获取
  信息，不分发原始音频。
- Zipformer 和 SenseVoice 模型权重不进入 GitHub 仓库或公开 Release。模型许可与
  运行时代码许可不是同一件事；若未来公开分发权重，必须另行完成模型许可审查。

详细来源与归属见仓库根目录的 `THIRD_PARTY_NOTICES.md`。

## 技术门禁结果

- Git 实际跟踪的媒体文件只有 `docs/assets/demo.gif`；未跟踪音视频、字体或模型权重。
- `.env`、`artifacts/`、本地数据、录音、日志和 Windows 私测产物均被忽略。
- 未发现真实 API Key、个人主目录、个人训练数据或外部二进制素材进入候选文件。
