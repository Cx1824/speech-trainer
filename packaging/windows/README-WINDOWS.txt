表达能力训练器 · Windows 好友测试包
=====================================

适用环境
--------
- Windows 10/11 64 位
- 需要联网完成首次安装、下载语音模型以及调用 DeepSeek
- 推荐使用最新版 Edge 或 Chrome，并允许本地网页使用麦克风

如何使用
--------
1. 把整个压缩包解压到普通文件夹，路径尽量不要太长。
2. 双击「启动训练器.cmd」。
3. 第一次启动会自动准备 Python 3.12、项目依赖和本地语音模型：
   - 依赖安装通常需要 3–8 分钟；
   - 语音模型下载约 300 MB，解压后约占 410 MB；
   - 下载速度取决于网络，请不要中途关闭窗口。
4. 安装完成后浏览器会自动打开。以后再次双击会直接打开。
5. 不使用时双击「停止训练器.cmd」。

本测试包已经配置
----------------
- 内容分析：DeepSeek（测试用共享 Key，前端不会显示 Key 原文）
- 实时字幕：本地 sherpa-onnx，训练音频默认不上传
- 面试官语音：Edge TTS，无需额外 Key

隐私与测试边界
--------------
- 训练记录、报告和上传材料只保存在解压目录的 backend\data、uploads、output。
- 测试结束后，先双击停止脚本，再删除整个解压目录即可清除本地记录和共享 Key 副本。
- 本地语音模型位于 %LOCALAPPDATA%\SpeechTrainer\models；如不再使用可手动删除。
- DeepSeek 会收到生成问题、点评和报告所需的文字内容，请勿输入敏感材料。
- 这是包含临时共享 API Key 的私人测试包：请勿上传 GitHub、网盘公开链接或转发给未授权人员。
- 包发起人测试结束后会在 DeepSeek 控制台撤销该 Key；仅删除压缩包不能撤销已经分发的副本。

故障排查
--------
- 启动失败时窗口会保持打开，不会闪退。请记录窗口中的错误编号。
- 如需反馈启动问题，请发送 .runtime\logs 内的 launcher-bootstrap.log、
  launcher.log 和 backend-error.log；不要发送 backend\.env，其中包含测试密钥。
- 提示没有 winget：请从 https://www.python.org/downloads/windows/ 安装 64 位 Python 3.12，再重试。
- 端口被占用：本程序不会关闭其他项目；请先关闭占用 17860 端口的程序。
- 页面打不开：查看 .runtime\logs\backend-error.log。
- 字幕无结果：确认浏览器麦克风权限已允许，并检查本地语音模型是否完整下载。
