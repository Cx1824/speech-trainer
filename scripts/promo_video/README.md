# 24.5 秒产品段宣传片源文件

`promo.html` 使用真实首页、实时训练页和报告截图作为基础素材，再通过 Canvas
绘制可复现的演示输入和品牌动效。演示文本不包含真实用户、简历、训练记录或密钥。

时间线固定为 1920×1080、15 fps、24.5 秒。页面中的隐藏按钮用于逐帧渲染，确保
不同机器上导出的镜头节奏一致。

最终成片、GIF 和预览图写入被 Git 忽略的 `artifacts/promo-video-v1/`，不会进入
正式应用或公开源码包。

商业开场、第三方生成素材和本地配音合成脚本不属于开源产品本身，默认被 Git
忽略。公开成片前必须自行确认画面、字体和声音的发布权利。

本地逐帧导出由 `server.py` 接收，只监听 `127.0.0.1`，并且只允许写入指定项目
目录中符合 `frame-000.jpg` 格式的 JPEG 文件。
